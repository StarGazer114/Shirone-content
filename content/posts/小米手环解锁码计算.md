在手环忘记密码时 ，可以通过解锁码来解锁，在忘记密码说明页面依次点击上下上下上上下下进入重置页面，获取SN和MAC地址  

:::note
如果这是你的设备，可以通过小米运动健康app来重置密码，无需使用解锁码
:::

一个可以计算解锁码的小工具[小米设备解锁码计算](https://blog.bear556.top/unlock)

旧版解锁码计算公式（适用于s5/10pro以前的设备）

```
unlock_code = SHA256(upper(MAC) + upper(SN) + "XIAOMI")
code = 取哈希前 10 个字节，每个字节对 10 取模，拼接成 10 位数字
```

新版解锁码计算公式（适用于s5/10pro及以后的设备）

```
unlock_code = SHA256(upper(SN) + upper(MAC) + "XIAOMI")
code = 取哈希前 10 个字节，每个字节对 10 取模，拼接成 10 位数字
```

:::warning
注意使用解锁码解锁后设备会恢复出厂设置
:::
